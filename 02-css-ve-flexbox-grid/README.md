# 02 - CSS, Flexbox ve Grid

Bu bölümde sayfaların görünümü CSS ile biçimlendirilir ve modern yerleşim teknikleri uygulanır.

## Dosyalar

| Dosya | Açıklama |
| --- | --- |
| `stil.css` | Ortak değişkenler (custom properties), kutu modeli, tipografi ve yerleşim sınıfları |
| `flexbox.html` | Flexbox ile gezinme çubuğu ve esnek kart sırası |
| `grid.html` | CSS Grid ile duyarlı kart ızgarası ve sayfa yerleşimi |

## Öğrenme Hedefleri

- Seçiciler, özgüllük ve kutu modeli
- `display: flex` ile tek eksenli yerleşim
- `display: grid` ile iki eksenli yerleşim
- `@media` ile mobil uyumlu tasarım

HTML dosyalarını tarayıcıda açın; pencereyi daraltarak duyarlı davranışı izleyin.
