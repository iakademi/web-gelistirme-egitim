# 04 - DOM ve Olaylar

DOM (Document Object Model), tarayıcının HTML sayfasını JavaScript ile değiştirilebilir bir ağaç olarak sunmasıdır.

## Dosyalar

| Dosya | Açıklama |
| --- | --- |
| `index.html` | Görev listesi arayüzü |
| `app.js` | Eleman seçme, olay dinleme, eleman ekleme/silme, olay delegasyonu, `localStorage` |

## Öğrenme Hedefleri

- `querySelector` ile eleman seçmek
- `addEventListener` ile olay dinlemek
- Elemanları dinamik oluşturmak ve silmek
- Olay delegasyonu ile tek dinleyiciyle çok sayıda elemanı yönetmek
- Verileri tarayıcıda `localStorage` ile saklamak

`index.html` dosyasını tarayıcıda açarak görev ekleyip silin; sayfayı yenilediğinizde görevlerin korunduğunu görün.
