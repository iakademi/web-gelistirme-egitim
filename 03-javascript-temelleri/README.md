# 03 - JavaScript Temelleri

Tarayıcı gerektirmeden Node.js ile de çalıştırabileceğiniz temel JavaScript örnekleri.

## Dosyalar

| Dosya | Açıklama |
| --- | --- |
| `temeller.js` | Değişkenler, veri türleri, koşullar, döngüler, fonksiyonlar |
| `diziler-ve-nesneler.js` | Dizi metotları (`map`, `filter`, `reduce`), nesneler, destructuring, spread |

## Çalıştırma

```bash
node temeller.js
node diziler-ve-nesneler.js
```

Node.js yoksa dosya içeriğini tarayıcı geliştirici araçlarının Console sekmesine yapıştırabilirsiniz.
