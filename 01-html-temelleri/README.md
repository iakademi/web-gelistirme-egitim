# 01 - HTML Temelleri

Bu bölümde bir web sayfasının iskeletini oluşturan HTML etiketleri anlatılır.

## Dosyalar

| Dosya | Açıklama |
| --- | --- |
| `index.html` | Anlamsal yapı (`header`, `nav`, `main`, `section`, `footer`), başlıklar, listeler, bağlantılar, tablo ve form örneği |

## Öğrenme Hedefleri

- Bir HTML5 belgesinin temel yapısını kurmak
- Anlamsal etiketleri doğru yerde kullanmak
- Form elemanlarını etiketlemek ve doğrulama özniteliklerini kullanmak

Dosyayı tarayıcıda açarak çıktıyı inceleyin, ardından etiketleri değiştirip sonucu gözlemleyin.
